# Reusable fixed contract witnesses

The Booking witness is used by the current
`examples/experiments-faults-v22.json` manifest. It validates the declared contract
on the original faulty source and on a separately corrected copy. The Shipping
witness remains a reusable correct-implementation control. These files are outside
model-visible project directories and are developer/AI-assisted, unreviewed inputs.

The old two-arm closed-loop study and its dedicated manifest were retired at the
owner's request. See [cleanup history](../../experiments/cleanup-v22.json) and the
[current evidence index](../../experiments/README.md). Runtime code and regression
fixtures are preserved. No human accuracy or natural-error repair result is implied.
