# B2/B3 closed-loop acceptance inputs

Four paid workflows: two existing synthetic development fixtures, two independent
full configurations and one repeat, with a common 16-request limit. This custom
subset is not the complete four-way baseline protocol, a held-out benchmark or a
diagnosis-only ablation. No generated candidates or expected model decisions are supplied.

Shipping is correct; booking contains the existing exclusive-threshold defect.
External fixed witnesses check stated values and types, including the separately
corrected booking copy. References are developer/AI-assisted and remain unreviewed.
They are never sent to the model. New witnesses do not make old inputs held out.
Natural generated errors, repair, admission rejection and preserved valid failures
are measured only if actually observed; missing opportunities remain unavailable.

```sh
npm run evaluate -- examples/experiments-closed-loop-smoke.json --validate-only
npm run evaluate -- examples/experiments-closed-loop-smoke.json
```

The first command only validates references. The second makes paid model calls;
failed attempts and resource usage remain saved without automatic replacement.
