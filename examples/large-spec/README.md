# Synthetic batching and context fixture

The project has 32 explicit finite echo requirements and two large comment-only
catalogue files unrelated to them. Combined retained source exceeds 200 KB; each
file remains below the archive per-file limit. This exercises actual whole-file
retrieval and batching without pretending to represent real application complexity.
The external oracle checks every stated value and semantic integer return type.
Padding is declared synthetic and is part of the frozen project archive.
