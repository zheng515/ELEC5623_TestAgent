Scope: Click 8.1.7 public command/option API. The complete upstream Python runtime is imported without patches. Define small local commands using click.command, click.option and click.echo and invoke them through click.testing.CliRunner. Each rule describes the explicitly stated cases only; no terminal, locale or operating-system guarantee is implied.

R1: For a command with option '--count' declared with default=1 and type=int, the callback receives the integer 1 when no option is supplied and the integer 3 for ['--count', '3']. A callback that echoes the count has exit_code 0 and output '1\n' and '3\n', respectively.

R2: For a command with '--count' of type=int, invoking ['--count', 'not-an-integer'] rejects the input with exit_code 2 and does not call the command callback.

R3: For a command with click.option('--message', multiple=True), the callback receives an empty tuple when no message is supplied and the ordered tuple ('first', 'second') for ['--message', 'first', '--message', 'second']; both invocations succeed with exit_code 0.

R4: For a command with click.option('--verbose', is_flag=True, default=False), the callback receives False with no arguments and True for ['--verbose']; both invocations succeed with exit_code 0.

R5: For a command with option '--hash-type' using click.Choice(['MD5', 'SHA1'], case_sensitive=False), the input 'md5' is accepted and delivered to the callback as the canonical choice 'MD5'. An input of 'sha256' is rejected with exit_code 2 and does not call the callback.

R6: For a command with option '--count' using click.IntRange(1, 3), the inputs '1' and '3' are accepted as integers 1 and 3 with exit_code 0. The inputs '0' and '4' are rejected with exit_code 2 and do not call the callback.
