# Fixed reference witnesses

The `oracles/` directory contains the shipping, booking and inventory witnesses
used by `tests/experiment-reference.test.ts`. They check integer-result contracts
and boolean exclusions on separately constructed source copies. These are
regression inputs, not current model experiments or independent human labels.

Unused historical projects, manifests and the duplicate repeat-protocol document
were removed. Active commands and observations are indexed in
[experiments/README.md](../../experiments/README.md).
