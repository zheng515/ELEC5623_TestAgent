# Preserved interrupted development experiment

This 36-run study was intentionally stopped after seven started attempts, including
one cancelled attempt. It is not the final experiment and missing runs are not
successes. The source snapshot and first outputs are retained unchanged.

shipping-B3-1 approved no tests because the model classified absent coverage as
incomplete requirements, despite clear integer/value/exception contracts. Separate
model review supported the proposals, but the program correctly enforced the
analysis clarification gate. No gate was relaxed to admit them.

The next policy separates original requirement quality from missing test evidence,
in both the common system instruction and structured issue-field description.
A separately frozen experiment evaluates that change; this failed attempt remains
part of development history. These observations are not independent accuracy labels.
